## 🚀 Experimente a urna

**Acesse agora:** https://sergioemerick517.github.io/simulador-urna/

Explore uma experiência inspirada no processo de votação brasileiro, com interface interativa, candidatos com fotos e registro de votos de demonstração compartilhados online.

## ✨ Destaques da Beta 5.0

- 🗳️ **Votação interativa** — experimente o fluxo de votação do simulador.
- 🌐 **Compartilhamento online** — os votos de demonstração são registrados em um banco de dados online.
- ⚡ **Atualização em tempo real** — novos registros podem ser sincronizados entre sessões abertas.
- 🧑‍💼 **Candidatos com fotos** — identificação visual durante a simulação.
- ⏳ **Tela de processamento** — uma barra de progresso acompanha o processamento simulado do voto.
- 🔊 **Feedback sonoro** — mais imersão durante a experiência.
- 💻 **Acesso pelo navegador** — não é necessário instalar um programa.

## 🧭 Como testar

1. Abra o simulador pelo botão acima.
2. Siga as instruções exibidas na tela.
3. Faça um voto de demonstração e observe a confirmação.
4. Se quiser testar a sincronização, abra o site em outro navegador e compare os registros.

## 🛠️ Tecnologias

- HTML, CSS e JavaScript
- GitHub Pages para publicação
- Supabase para armazenamento online e sincronização dos registros

## 📌 Sobre o projeto

O **Simulador da Urna Eletrônica — Beta 5.0** é um projeto independente, criado para demonstração e experimentação de uma interface de votação.

> **Aviso:** este projeto não é oficial, não é afiliado ao Tribunal Superior Eleitoral (TSE) e não deve ser utilizado para eleições reais ou para registrar votos oficiais. Os registros são dados de demonstração e o sistema não oferece as garantias de segurança, auditoria e sigilo exigidas em uma eleição real.
